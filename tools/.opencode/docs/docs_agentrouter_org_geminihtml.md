# 在 Gemini Cli 中使用 Agent Router [​](#在-gemini-cli-中使用-agent-router)

Gemini Cli 暂时不支持配置自定义路由，暂不支持使用。你可以选择使用 [Roo Code](/roocode.html) 或 [Qwen Code](/qwencode.html) 来使用 AgentRouter。
